# MARRYSET 婚宴排桌小幫手

台灣婚宴圓桌排桌工具，純前端網頁，資料只存在你自己的瀏覽器，不會上傳到任何伺服器。

## 功能

- 匯入 Google 表單回覆（Excel .xlsx / CSV），自動讀取姓名、男女方、關係、出席人數、同行親友、素食、兒童椅、飲食禁忌
- 「禮到人不到 / 無法出席」自動排除
- 依「男女方＋關係」自動分桌，同行的人一定坐在一起
- 拖曳到座位小圓圈；拖到有人的座位會互換；拖回左邊取消入座（手機也能拖）
- 桌子可在平面圖上自由移動、改名、調整每桌人數（8–12 人皆可）
- 回覆變多時再匯入一次，已排好的人會留在原位
- 匯出平面圖 PNG、各桌名單 PNG、CSV
- 儲存 / 載入 .json 存檔，可交給新人接著排

## 使用

開啟 GitHub Pages 網址，或直接用瀏覽器打開 `index.html`。
